# Raihona

**A browser-based Silk Road exploration game prototype built with vanilla HTML, CSS, and JavaScript.**

Raihona is an interactive cultural storytelling experiment centered on movement through a stylized Silk Road map. The project combines a lightweight game loop with place-based scenes, NPC dialogue, and small interactive moments across Central Asian locations.

## What it demonstrates

- Building an interactive browser experience without a framework
- State-driven movement between map and city scenes
- DOM-based character and dialogue interactions
- Custom CSS layout and visual styling
- JavaScript game logic, event handling, and UI state management
- Translating cultural/research interests into an interactive product concept

## Current prototype

The current code includes:

- A navigable Silk Road map
- City nodes including **Bukhara, Samarkand, and Kabul**
- A nomadic-camp starting area
- Character/NPC interactions and dialogue containers
- Scene transitions between the world map and individual locations
- A small **Flappy Camel** mini-game concept

## Stack

`HTML` · `CSS` · `JavaScript`

No front-end framework is required.

## Repository structure

- `index.html` — interface and scene structure
- `game.js` — movement, interactions, game state, dialogue, and mini-game logic
- `style.css` — main visual system and layout
- `bobojon_center_final.css` — character-specific presentation styles

## Public-snapshot note

This repository currently contains the code layer of the prototype. The image asset directory referenced by the interface is not included in this public snapshot, so a fresh clone will not reproduce the complete visual build without those assets.

## Why I built it

I am interested in the intersection of **technology, systems thinking, culture, and human experience**. Raihona began as a way to experiment with interactive storytelling while learning how a browser-based product is structured: how information moves, how states change, how users orient themselves, and how small design decisions affect the experience.

The project is intentionally exploratory rather than production software, but it reflects the same approach I bring to operational work: understand the system, make the moving parts visible, and build something people can actually navigate.
